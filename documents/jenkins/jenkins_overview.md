# Jenkins Overview

## Purpose
Jenkins is an automation server commonly used for continuous integration and continuous delivery. It can automate build, test, and deployment tasks.

## Core concepts

### Job
A Jenkins job defines work that Jenkins should execute.

### Pipeline
A Pipeline defines build, test, and deployment stages as code, commonly using a Jenkinsfile.

### Agent
An agent is an environment where Jenkins runs build steps.

### Plugin
Plugins extend Jenkins functionality.

### Credential
Credentials store secrets and authentication details used by jobs or pipelines.
