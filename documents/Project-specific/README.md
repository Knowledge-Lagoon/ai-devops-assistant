# Project-Specific DevOps Knowledge Base

Place approved internal documents here, such as:

- Application deployment runbooks
- Support model and escalation process
- Environment access notes
- Architecture documents
- Standard operating procedures
- Incident response guides
- Known issues and workarounds
- Patching coordination notes
- Backup and restore procedures

## Suggested file naming convention

```text
<application>_<environment>_<topic>_<yyyy-mm-dd>.md
```

Example:

```text
abcapp_sat_deployment_runbook_2026-07-27.md
```

## Recommended metadata header

```yaml
application: 
environment: 
technology: 
owner_team: 
support_contact: 
last_reviewed_date: 
confidentiality: internal
```
